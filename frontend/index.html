Introduction

Ekhane amra TouhedaLanguage-er basic code theke aste aste programming shikhbo.

My First Code

dekhao("Hello World")

Basic Rules

  • Code lekhar jonno nijer language-er keyword use korte hobe.
  • String lekhar jonno double quotation use korte hobe.
  • Condition ebong loop-er jonno parentheses use korte hobe.
  • Code block-er jonno curly braces use korte hobe.
  • Protiti statement alada line-e lekha jabe.

Variables

Variable-er moddhe amra kono value rekhe pore seta use korte pari.

Syntax

dhori variableName = value

Example

dhori name = "Touheda"
dhori age = 20

dekhao(name)
dekhao(age)

Output

Touheda
20

Data Types

If Else

Kono condition true naki false seta check korar jonno jodi ebong nahole use kori.

Syntax

jodi(condition) {
    // code
} nahole {
    // code
}

Example

dhori age = 20

jodi(age boro ba soman 18) {
    dekhao("Adult")
} nahole {
    dekhao("Minor")
}

Output

Adult

Loops

Ekoi kaj koyekbar korar jonno loop use kora hoy.

Syntax

Example

loop(5) {
    dekhao("Hello")
}

Functions

Function use kore amra ekta kajer code alada kore likhe pore abar use korte pari.

Example

function jog(a, b) {
    return(a + b)
}

dhori result = jog(10, 20)
dekhao(result)

Output

30
